DROP ICON PACKS HERE

Create one folder per icon pack, for example:
  icons/frutiger/
  icons/xpish/
  icons/custom1/

Inside each pack folder, use these exact filenames:
  my_computer.png
  my_documents.png
  internet_explorer.png
  recycle_bin.png
  start_logo.png        (optional)

PNG with transparency is recommended. 256x256 is plenty for desktop icons.

Windroid can list these pack folders in Appearance settings after the next APK build/update.
